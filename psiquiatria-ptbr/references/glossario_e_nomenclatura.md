# Glossário e nomenclatura clínica (inglês → português do Brasil)

Referência da camada `psiquiatria-ptbr`. Complementa o glossário psicométrico do núcleo
(`shared/references/psychometric_terminology_glossary.md`). Na dúvida entre duas
traduções, preferir o termo do **DeCS** (decs.bvsalud.org), porque é o que indexa a
literatura em português.

---

## 1. Sistemas diagnósticos

| Sistema | Situação | Regra de escrita |
|---|---|---|
| **DSM-5-TR** (2022) | Referência em pesquisa e na maioria dos periódicos | Citar "DSM-5-TR" e não "DSM-5" quando os critérios usados forem os da revisão de texto. |
| **CID-11** | Em vigor na OMS desde 2022 | Citar o código com o capítulo (por exemplo, 6A70 para episódio depressivo único). |
| **CID-10** | Ainda usada em registros e sistemas de saúde brasileiros | Em estudos com dados do SUS ou de prontuário, declarar qual versão codificou os diagnósticos e como foi feita qualquer conversão. |

Nomenclatura de psicofármacos: preferir a **Nomenclatura Baseada em Neurociência (NbN)**
quando for relevante ao argumento (por exemplo, "antagonista de receptor de dopamina e
serotonina" em vez de "antipsicótico atípico"), mantendo a classe tradicional entre
parênteses na primeira menção. Usar o nome genérico (DCB), não o comercial; o nome
comercial só aparece quando o produto específico importa (por exemplo, escetamina
intranasal).

## 2. Linguagem não estigmatizante

| Evitar | Preferir |
|---|---|
| "o esquizofrênico", "os bipolares" | "pessoa com esquizofrenia", "pacientes com transtorno bipolar" |
| "cometeu suicídio" | "morreu por suicídio" |
| "suicídio bem-sucedido" ou "fracassado" | "suicídio" e "tentativa de suicídio" |
| "viciado", "drogado", "dependente químico" | "pessoa com transtorno por uso de substâncias" |
| "abuso de substância" (quando o critério for o do DSM-5) | "uso de substância" com o especificador de gravidade |
| "sofre de depressão" | "tem depressão" ou "apresenta episódio depressivo" |
| "doente mental" | "pessoa com transtorno mental" |
| "manipulador" (em relato de caso) | descrever o comportamento observado |

## 4. Falsos cognatos e anglicismos comuns em textos médicos

| Evitar | Preferir | Motivo |
|---|---|---|
| "severo" (para *severe*) | "grave" | "Severo" em português é "rigoroso". |
| "suportar" (para *support*) | "sustentar", "corroborar", "apoiar" | |
| "eventualmente" (para *eventually*) | "por fim", "com o tempo" | "Eventualmente" significa "ocasionalmente". |
| "atualmente" (para *actually*) | "na verdade" | |
| "evidência" (para *evidence*) no sentido de "prova" | "evidência" está consagrado; evitar "evidências demonstram", que sugere prova | |
| "performance" | "desempenho" | |
| "droga" (para medicamento) | "medicamento", "fármaco" | "Droga" em português remete a substância de uso não médico. |
| "baseline" | "linha de base", "início do estudo" | |
| "follow-up" | "seguimento" | |
| "screening" | "rastreamento" ou "rastreio" | |
| "trial" | "ensaio" | |
| "assessment" | "avaliação" | |
| "design" do estudo | "delineamento" ou "desenho" | |
